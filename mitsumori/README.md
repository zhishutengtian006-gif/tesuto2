# 住宅見積ナビ

見積Excel（`見積書_2026.08.19.xlsm`）の積算ロジックを Web に移植した、営業向けの住宅見積システムです。
図面（平面・立面・求積図の PDF）を見ながら、サッシや建具をタップで選ぶだけで御見積書までできます。

- ブラウザだけで動きます（サーバ不要。`index.html` を開くだけ）
- 計算は Excel と 1 円単位で一致することをテストで確認しています（`tests/engine.test.js`）
- 単価は Excel から自動抽出するので、単価改定は Excel を直してスクリプトを再実行するだけです

## 営業さんの操作の流れ

| 画面 | やること |
|---|---|
| 1 基本情報 | お施主様名・工事名、仕様（フジタ／PG／STO）、階数、見積区分（通常／簡易／紹介／紹介簡易 → 区分ごとの原価率） |
| 2 図面・面積 | 求積図の㎡を入力（坪は自動換算）。図面PDFを開けば、縮尺を選んで**囲むだけで面積・長さを計測**。図面の文字から「建築面積 66.25㎡」やサッシ寸法コード（16509 など）を**自動で読み取り**、タップで反映 |
| 3 サッシ | 「標準セットを読込」→ 変えたい窓だけ差し替え。種類とサイズのボタンをタップで追加、ガラス（透明／フロスト）・オーダー・樹脂アングルを切替。**標準との差額だけがオプション**になり、取付手間も自動増減 |
| 4 建具 | 既製建具（大栄建材：デザイン・表示錠・特寸）と造作建具（搬入取付費は枚数で自動） |
| 5 収納 | 固定棚・可動棚（標準4面との差額、大工手間込み） |
| 6 電気・設備 | 居室・非居室の増減で配線・スイッチ・コンセント・照明が自動増減。コンセント等の個別増減、第一種換気、2Fトイレ・手洗 |
| 7 外部・内部OP | 軒の出・下屋・目隠し塀・パラペット・高基礎・瓦・和室・法22条・床仕上げ等。単価表にある建材OPは数量を入れるだけ。自由入力行もあり |
| 8 付帯・申請 | 付帯工事（お客様向け定額）、確認申請・性能評価・BELS・長期優良・瑕疵保険 |
| 9 見積書 | 御見積書（A 本体＋付帯／B 申請費用他／C オプション）＋オプション内訳明細。印刷・PDF保存、Excel貼り付け用コピー。社内用の原価・粗利（印刷されない） |
| 10 積算明細 | Excel「契約内訳」と同じ全行。数量・原価単価を上書きでき（黄色表示）、自動計算より優先 |

入力内容はこの端末のブラウザに自動保存されます。別の端末へ移すときや保管するときは「保存」（JSON ファイル）→「読込」を使ってください。

## セットアップ

```bash
# 1. 単価マスタを Excel から作る（原価を含むので公開リポジトリには置かない）
pip install openpyxl
python3 tools/extract_master.py /path/to/見積書_2026.08.19.xlsm   # → js/master-data.js

# 2. 動作確認（Excel との突合テスト）
node tests/engine.test.js

# 3. index.html をブラウザで開く
```

社内で共有する場合は、`mitsumori/` フォルダ一式を社内サーバ（または非公開の GitHub Pages 等）に置いてください。
図面PDFの表示と日本語フォントは CDN（cdnjs / Google Fonts）から読み込むため、インターネット接続が必要です。

### 単価を改定したとき

Excel 側（②ｻｯｼ の定価・掛率、③既建 の NET 率、契約内訳の単価など）を直して保存し、
`python3 tools/extract_master.py 見積書.xlsm` を再実行するだけです。数量の出し方（`js/engine.js`）は変更不要です。
行を追加・削除して「契約内訳」の行番号がずれた場合は、`js/engine.js` の `RULES`（行番号 → 数量式）を合わせてください。

## 計算の仕組み（Excel との対応）

```
入力（基本情報・面積・選択商品）
  └ derive()          … 入力用シート：㎡→坪（×0.3025 小数2桁切捨て）、延床・施工面積・下屋・断熱境界
  └ 商品モジュール     … ②ｻｯｼ・③既建・④造建・⑤固棚・⑥可棚・⑦電気・⑧配管・①大工
  └ 契約内訳エンジン   … 行ごとに 数量 × 原価単価（×NET率） → 計上単価 = ROUNDUP(原価÷原価率, 10円/100円)
                          一式行は ROUNDUP(計上単価×数量, 100円/1000円)、それ以外は ROUNDDOWN
  └ 見積書            … Ａ 本体（施工坪×坪単価）＋付帯（定額）、Ｂ 設計費・申請費・諸経費、Ｃ オプション
```

- **坪単価（自動）**：本体＋付帯＋申請費用他の合計が、積算（標準工事＋付帯＋諸経費＋設計・申請）と一致する本体金額を求め、100円単位で切り上げています。Excel の「調整入力①：見積書の坪単価算定」を手で合わせていた作業の自動化です。手入力で上書きもできます。
- **諸経費**：Excel と同じく ROUNDUP((Ａ税込＋Ｃ税込)×2%÷1.1, 千円)。
- **サッシ**：原価 = 定価×掛率＋網戸×掛率＋他金額＋窓台額縁（オーダーサイズ係数・樹脂アングル加算）、売価 = ROUNDUP(原価÷原価率, 100円)。選択があれば「選択合計 − 標準合計」がオプション。
- **既製建具**：標準仕様は Excel の標準原価をそのまま使用。デザイン加算・表示錠・特寸は Excel の NET 率・特寸係数で加算。

## Excel を移植していて見つかった点（要確認）

| # | Excel の状態 | 本システムの扱い |
|---|---|---|
| 1 | 契約内訳241行（廻縁①）の数量式が `入力用!B14`（敷地外周）を参照しており、敷地外周が空欄だと計上されない | 他の巾木行と同じく「仕様」で判定して計上 |
| 2 | 内部足場の大工手間が ①大工 G42 と 契約内訳685行の両方で計上され二重になる | 685行のみで計上 |
| 3 | 既製建具の標準台数に「取付費」の行が1台として数えられている（9台） | 大工標準手間に効くため踏襲（1台分の取付手間が多く乗る） |
| 4 | 契約時の既製建具取付手間（699行）の数量が空欄で計上されない | 踏襲（必要なら積算明細で数量入力） |
| 5 | 見積書の「電気工事 変更差額」「照明器具 変更差額」が「別途」で、⑦電気の増減金額が見積に入らない | ⑦電気の増減をＣ欄「電気工事 変更差額」に計上 |
| 6 | 設備配管変更追加（930行）が原価のみで売価0 | ⑧配管の「追加料金」で売価を計上 |
| 7 | 固定棚を1行も入力しないと、標準棚が全額マイナスになる | 未入力なら標準のまま（1行でも入れたら差額計算） |
| 8 | 外壁を他仕上げにしたとき、サイディングは原価のみ控除（売価は残る） | 踏襲 |
| 9 | 上棟レッカーの「75坪以上で3日」は条件の順番の都合で到達しない | 踏襲（50坪以上は2日） |

既製建具の一部の行は Excel 上で行ごとに式が異なるため、デザイン加算・特寸は標準的な式に揃えています（近似）。
PG 標準の既製建具の原価は「原価（加工無）」で近似しています。

## ファイル構成

```
mitsumori/
  index.html               画面
  css/app.css              スタイル（印刷時は御見積書のみ A4）
  js/engine.js             積算エンジン（Excel の計算式の移植）
  js/app.js                画面・操作
  js/plan.js               図面PDFビューア（縮尺・計測・文字読取り）
  js/master-data.js        単価マスタ（Excel から自動生成・リポジトリには含めない）
  tools/extract_master.py  Excel → 単価マスタ 抽出ツール
  tests/engine.test.js     Excel との突合テスト
```
